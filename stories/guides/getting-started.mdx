# Getting started

Qeetrix is two packages: `@qeetrix/ui` holds the components and design tokens, and
`@qeetrix/icons` holds the icons and the Qeet logo — the icons `@qeetrix/ui` draws itself.

## Install

```bash
bun add @qeetrix/ui @qeetrix/icons react react-dom
```

## Wire up styles (Tailwind v4)

In your global stylesheet, import the Qeetrix layer once, and let Tailwind see the
component classes:

```css
@import "@qeetrix/ui/styles.css";
@source "../node_modules/@qeetrix/ui/dist/**/*.js";
```

## Use it

```tsx
import { QeetLogo } from "@qeetrix/icons";
import { ThemeProvider, Button, Card, CardContent } from "@qeetrix/ui";

export function App() {
  return (
    <ThemeProvider defaultTheme="system">
      <Card>
        <CardContent className="flex items-center gap-3">
          <QeetLogo height={28} className="dark:hidden" />
          <QeetLogo height={28} variant="dark" className="hidden dark:block" />
          <Button>Authenticate with Qeet</Button>
        </CardContent>
      </Card>
    </ThemeProvider>
  );
}
```

Light and dark are driven by the `.dark` class, which `ThemeProvider` manages. RTL is
handled by `DirectionProvider`.

## Import surfaces

- `@qeetrix/ui` — the barrel (all components, hooks, `cn`)
- `@qeetrix/ui/styles.css` — tokens + fonts + base layer
- `@qeetrix/icons` — every icon (`StarIcon`, …) and `QeetLogo`; `@qeetrix/icons/icons/<id>` for one icon
- `@qeetrix/ui/components/<slug>` — deep import for a single component (tree-shaking)
- `@qeetrix/ui/tokens.css` / `@qeetrix/ui/tokens.json` — raw design tokens

See **Theming** and **Design tokens** for customisation.
